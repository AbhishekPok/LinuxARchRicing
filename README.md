# Arch + Hyprland rice: amane, mac-style + DevOps

A keyboard-first Hyprland desktop on Arch. The bar, notch, Control Center,
launcher and lock screen are all one Rust program, the **amane shell**. Colours
come from theme-manager palettes, and every UI font is JetBrainsMono Nerd Font.

> The previous waybar / swaync / wofi / wlogout setup is tagged
> [`waybar-era`](../../tree/waybar-era): `git checkout waybar-era`.

## What's in here

Files sit at the paths they use under `$HOME`.

| Path | What |
|---|---|
| `.config/amane/` | The shell: menu bar, notch with Live Activities, Control Center, Spotlight-style search with keyword modes, settings, lock screen (`src/lock.rs`) |
| `.config/hypr/` | Hyprland **Lua** config (`hyprland.lua`), hypridle, hyprlock fallback, `keybinds.md`, and the scripts the shell and keybinds call (`scripts/`) |
| `.config/theme-manager/themes/` | Palettes: graphite, carbon, catppuccin, dracula, gruvbox, nord, rosepine, tokionight, kali-neon, aquarium, chadtain |
| `.config/kitty/` | Terminal config, a work tab session, the active theme |
| `.config/fontconfig/` | Font fallbacks (JetBrainsMono / GeistMono Nerd Font, Inter, Noto) |
| `.config/gtk-3.0`, `.config/gtk-4.0` | `settings.ini` only; the CSS is generated by theme-manager |
| `.config/fastfetch/` | fastfetch config and logos |
| `.local/bin/` | `track` (run a command as a notch Live Activity), `chrome-theme-sync`, `kbb-scrolllock.sh` |
| `.local/share/sddm-ashwa-min/` | SDDM login theme, with its own `install.sh` / `rollback.sh` |
| `Pictures/Wallpapers/` | Nine original mac-style wave wallpapers, 2880x1800 |
| `tools/wavegen/` | Std-only Rust generator for the green wallpapers (meadow, fern, valley) |
| `patches/` | Local changes to the two upstream projects below |

## Upstream projects

Their source isn't copied here. Clone them at the pinned commit and apply the patches.

| Project | Upstream | Base | Patches |
|---|---|---|---|
| amane framework + CLI | <https://github.com/MystiaFin/amane> | `544cbfc` | `patches/amane/0001-0004`: framework fixes, crash supervisor, hyprlock handover on a crash while locked, idle poll backoff |
| theme_manager (`theme-set`, `theme-daemon`) | <https://github.com/adrsha/theme_manager> | `b40744b` | `patches/theme_manager/0001-waybar-writer.patch` (only needed if you still run waybar) |

```sh
git clone https://github.com/MystiaFin/amane ~/Projects/amane
cd ~/Projects/amane && git checkout -b mac-shell-perf 544cbfc
git am /path/to/this/repo/patches/amane/*.patch
cargo install --path .          # installs ~/.cargo/bin/amane

git clone https://github.com/adrsha/theme_manager ~/Projects/theme_manager
cd ~/Projects/theme_manager && git checkout b40744b
git apply /path/to/this/repo/patches/theme_manager/*.patch   # optional
cargo install --path .          # theme-set, theme-daemon
```

## Install

```sh
./install.sh          # copies everything into $HOME; anything it replaces goes to ~/.rice-backup-<time>/
```

Then:

1. Build and start the shell: `amane compile` and `amane run`. Hyprland starts it
   through `amane supervise`, which restarts it after a crash.
   `.config/amane/Cargo.toml` is written by the amane CLI and has absolute
   paths for the user who built it, so run `amane compile` again after cloning.
2. Pick a theme with `theme-set graphite`. That generates `hypr/colors.lua`,
   `theme_env.lua`, the GTK CSS and the kitty theme.
3. SDDM theme: add your own square `face.png` to
   `.local/share/sddm-ashwa-min/ashwa-min/`, then run its `install.sh` with sudo.

## Keys

The full list is in [`.config/hypr/keybinds.md`](.config/hypr/keybinds.md). The main ones:

| Keys | Action |
|---|---|
| `SUPER + Space` | Search / launcher. Type a keyword and a space for a mode: `clip`, `emoji`, `wall`, `win`, `proj`, `edit`, `aws`, `audio`, `display`, `keys`, `kitty`; `s <text>` searches the web |
| `SUPER + X` | Utility row: screenshots (w/r/f), lock, sleep, logout, reboot, power off |
| `SUPER + SHIFT + A` | Control Center |
| `SUPER + SHIFT + B` | Toggle the menu bar |
| `SUPER + SHIFT + L` | Lock |
| `SUPER + ALT + I` | Keep Awake |

## Battery

`scripts/power-mode.sh` switches on power_supply udev events. On battery it sets
the power-saver profile, turns blur and shadows off, and caps brightness at 50%.
On AC it restores them. The shell backs off its polling when idle (about 154
wakeups/s, down from 359).
